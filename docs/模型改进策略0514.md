### 4. 解决可能的“类别不平衡” (类不齐导致的假高准确率)

**如何提升：**
*   如果你发现某类识别极差，可以在 Task 2 的 `CrossEntropyLoss` 中加入类别权重 (Weight)，给少数类增加惩罚：

*   YOLO 模型中，如果小样本类别测的极差，也可以手动微调 Focal Loss 或者调整数据集构成比例。

**注意力机制（Attention Mechanism）**是深度学习中非常强大的一个概念。简单来说，它的灵感来源于人类的视觉：当你看一个装有水的杯子时，你的眼睛会自动忽略桌面的纹理、背景的墙壁，**只把目光“聚焦”在水面边界和水面反光上**。

在深度学习中，图像有成千上万个像素，普通的卷积网络（像你现在用的标准 ResNet 和 YOLOv8）会像“撒胡椒面”一样去同等处理整张图片。而**注意力机制则是一段额外的数学算法模块，它能计算出哪些区域或特征更重要，并给它们赋予更大的权重（乘以接近 1 的系数），同时把不重要的背景噪音压制掉（乘以接近 0 的系数）**。

### 它能帮助你改进模型吗？
**绝对可以，而且在数学建模竞赛中，这是拿高分的“杀手锏”！** 具体帮助体现在以下两点：

#### 1. 解决当前任务的痛点（性能提升）
瓶子往往是**透明或半透明**的，非常容易受到背景颜色、杂光环境和倒影的干扰（题目要求应对多种姿态和背景）。
*   如果没有注意力，模型可能会把背景里类似液体的颜色误判为瓶里的液体。
*   **加入注意力机制后**，模型会学会寻找特征（例如玻璃与液体交界处那条明显的折射横线，或是液面的边缘），**大幅提升识别的抗干扰能力和准确率**。

#### 2. 大幅提升论文的“含金量”（评委喜好）
如果是单纯调用写好的 ResNet18 或 YOLO 库，在数学建模里叫“调包”，体现不出算法设计能力。
但在论文中写上：**“基于透明瓶体容易受背景反光干扰的痛点，本文在 ResNet 骨干网络中引入了 CBAM（卷积块注意力模块），通过空间注意力与通道注意力相乘的空间特征重标定，提升了特征提取的鲁棒性……”**，然后在论文里列出 注意力机制的矩阵乘法和 Sigmoid 公式。这在评委眼中就变成了**实打实的“算法改进与创新”**，是区分普通奖和一等奖的核心亮点！

---

### 常用的轻量级注意力机制有这两种：
1. **SE 注意力 (Squeeze-and-Excitation)**：评估特征通道的权重，模型会知道“哪些特征代表了液面”，然后把这些特征放大。
2. **CBAM (Convolutional Block Attention Module)**：这是空间+通道的双重注意力，它不仅关注“什么是液体特征”，还在整张图的维度上寻找“液体特征出现在哪片区域”。
