要进一步压榨模型的性能，提升分类的准确性，可以从以下几个维度进行最小幅度的代码修改（按性价比排序）：

### 1. 引入“早停”与“保存最佳模型”（强烈建议）
**现状**：代码目前是在 `for epoch in range(epochs):` 循环结束后，直接保存**最后一次**的权重 (`torch.save(model.state_dict(), save_path)`)。如果模型在第 15 轮就已经达到了最好的泛化能力，到第 20 轮可能已经过拟合，导致最终保存的模型并不是最优的。
**改进方法**：在训练循环中记录验证集的最高准确率，只保存表现最好的那一轮的模型。
```python
    # 在循环开始前定义一个变量记录最佳准确率
    best_val_acc = 0.0
    
    for epoch in range(epochs):
        # ... 原有的训练和验证过程 ...
        
        val_acc = 100. * val_correct / val_total
        print(f"Epoch [{epoch+1}/{epochs}] | Loss: ... | Train Acc: ... | Val Acc: {val_acc:.2f}%")
        
        # 【新增】只在验证集表现更好时才保存模型
        if val_acc > best_val_acc:
            best_val_acc = val_acc
            os.makedirs('runs/task2', exist_ok=True)
            save_path = 'runs/task2/resnet18_二分类权重_best.pth'
            torch.save(model.state_dict(), save_path)
            print(f"🌟 发现更好的模型！已更新保存至: {save_path}")
```
*(并在最后生成图表/测试前，用 `model.load_state_dict(torch.load(save_path))` 把最佳模型加载回来进行画图)*

### 2. 添加学习率调度器 (LR Scheduler)
**现状**：当前使用的固定学习率 `1e-4`。在深度学习中，训练后期如果学习率不下降，模型会在最优解附近不停震荡，无法损失降到最低。
**改进方法**：引入**余弦退火算法 (Cosine Annealing)** 动态衰减学习率。这能在论文中增加“**使用了余弦退火策略动态调整学习率，避免陷入局部最优**”的论述点。
```python
    # 在 optimizer 初始化下方加入：
    optimizer = optim.Adam(model.parameters(), lr=1e-4)
    scheduler = optim.lr_scheduler.CosineAnnealingLR(optimizer, T_max=epochs)
    
    for epoch in range(epochs):
        # ... 原有的训练逻辑 ...
        
        # 在每一轮 epoch 的最后（注意是在 train_loader 循环外面）步进一次
        scheduler.step()
        curr_lr = scheduler.get_last_lr()[0]
        # 可以顺便在 print 中把当前学习率打印出来
```

### 3. 加入标签平滑 (Label Smoothing)
**现状**：使用的是标准的 `nn.CrossEntropyLoss()`。对于裁剪出来的液体/空瓶，有时存在边界模糊（例如非常少量的液体），标准的交叉熵会强迫模型输出 100% 确定的概率，极其容易导致过拟合（Overconfidence）。
**改进方法**：开启标签平滑（给真实的 1 和 0 标签加入微小的噪声，如 0.9和0.1），提升泛化能力。
```python
    # 将原来的 criterion 替换为带标签平滑的版本
    criterion = nn.CrossEntropyLoss(label_smoothing=0.1)
```

### 4. 增强对抗遮挡的数据增强 (Random Erasing)
**现状**：使用了翻转、色彩抖动和旋转。
**改进方法**：对于液体检测，可以加入类似 **随机擦除 (Random Erasing)**，强迫网络不只盯着某个特定的高光点，而是全局寻找液体特征。
```python
    train_transform = transforms.Compose([
        transforms.Resize((224, 224)),
        transforms.RandomHorizontalFlip(p=0.5),
        transforms.ColorJitter(brightness=0.2, contrast=0.2, saturation=0.2),
        transforms.RandomRotation(degrees=15),
        transforms.ToTensor(),
        transforms.Normalize(mean=[0.485, 0.456, 0.406], std=[0.229, 0.224, 0.225]),
        # 【新增】随机遮挡部分图片像素
        transforms.RandomErasing(p=0.2, scale=(0.02, 0.1), value=0, inplace=False)
    ])
```

### 5. L2 正则化 (Weight Decay)
**改进方法**：在 Adam 优化器中添加 `weight_decay`，限制网络权重过大，这是缓解数据量较小时过拟合的标准手段。
```python
    optimizer = optim.Adam(model.parameters(), lr=1e-4, weight_decay=1e-5)
```
